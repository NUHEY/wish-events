# WISH Events

**寮のイベント・連絡・相談を、スマートフォンからひとつの場所で。**

[WISH Eventsを開く](https://wish-events-info.vercel.app)

早稲田大学国際学生寮WISHの寮生、RA、寮・大学関係者のためのWebアプリです。イベントへの参加から当日の連絡、日程調整、生活の相談までをまとめて扱えます。アプリのインストールは不要です。

## 最初のログイン

| 利用者 | ログイン方法 |
| --- | --- |
| 寮生・RA | 早稲田大学のGoogleアカウントでログインし、初回プロフィールを登録します。RA権限は運営側が設定します。 |
| 寮・大学関係者 | ログイン画面で関係者の区分を選び、案内されたパスワードを入力します。メールアドレスの入力は不要です。 |

関係者には区分に応じた名前が表示されます。管理機能はRAが許可した範囲で利用できます。管理メニューが出ない場合はRAに確認してください。共有パスワードを公開資料やトークに載せないでください。

## 画面下の4つのタブ

| タブ | 使いどころ |
| --- | --- |
| ホーム | お知らせ、イベント、回答が必要な項目を確認するとき |
| イベント一覧 | イベントを探し、詳細を確認して申し込むとき |
| トーク | イベント・フロア・友達との連絡を確認するとき |
| ツール | イベント募集、日程調整、RAへの相談、共有リンクなどを使うとき |

右上の自分の画像からマイページ・管理ボード・自分の設定などを開けます。言語や画面の明るさは「自分の設定」、登録情報は「プロフィールと公開範囲」で変更します。使い方ガイドも設定から見直せます。

## イベントを探して参加する

1. 「イベント一覧」を開き、気になるカードを押します。
2. 絞り込む場合は「フィルター」からカテゴリを選びます。日付はカレンダーで指定できます。
3. 日時・場所・参加費・申込条件を確認して申し込みます。事前質問があれば回答します。
4. 参加後はトークで当日の案内を確認します。アンケートがある場合はイベントの案内から回答します。

受付終了・満員・キャンセル条件は各イベントの表示を確認してください。支払い確認は運営側が行うため、支払い直後に反映されないことがあります。

## ツールの使い方

公開中の機能だけが寮生の画面に表示されます。「BETA」は試験公開中の目印です。

| ツール | 寮生ができること | RAができること |
| --- | --- | --- |
| イベントを募集 | 食事や外出などの仲間を募集する | 募集内容を確認し、イベント運営に活用する |
| みんなの日程調整 | ページを作成・共有し、空いている時間を入力する | 同じ操作でチームや企画の日程を調整する |
| Let's Chat! | フロアRAが公開した空き時間から予約する | 予約ページを作り、予約・実施状況を管理する |
| URS 日程調整 | RAが共有したページに予定を入力する | ルームメイトとRAが集まれる日程を調整する |
| WISH知恵袋 | 質問・回答する。RAだけへの非公開相談も選べる | RA限定の相談に回答し、質問を管理する |
| RAリンクページ | 外泊届やSNSなど、公開されたリンクを開く | 自分の共有リンクページを作成・編集する |
| 共有QRコード | リンクをQRコードにして画像で保存する | イベントや日程のURLを掲示物・案内へ載せる |

日程の空き時間は選択後に保存してください。予約できる時間がない場合は、RAが公開するまで待つか、RAへ確認してください。

### WISH知恵袋の公開範囲

投稿前に「質問を見られる人」と「回答できる人」を選びます。

- **全員が閲覧・全員が回答**：寮生活の知識を共有したいとき。
- **全員が閲覧・RAだけが回答**：RAの回答をみんなにも共有したいとき。
- **投稿者本人とRAだけが閲覧**：個別に相談したいとき。回答もRAに限定されます。

非公開相談は管理権限を持つ関係者にも表示されません。旧「RAへの質問箱」は知恵袋に統合されています。過去の質問の匿名・非公開設定は保持されます。緊急時にはこの投稿の返信を待たず、寮の指定連絡先へ直接連絡してください。

## トーク

イベント、フロア、友達の会話を切り替えて利用します。利用できる種類は公開設定によって異なります。メッセージや写真の送信、返信、リアクションなどが使えます。詳細画面の参加者アイコンから、その会話の参加者を確認できます。

トーク内の運営ツールパネルはありません。イベントの編集・アンケートなどの運営業務は、管理ボードやイベント詳細から行います。

## RA・関係者の管理ボード

右上の自分の画像から「管理ボード」を開きます。利用できる機能だけが管理メニューに表示されます。

- **投稿・配信**：イベント、お知らせ、対象を指定した通知。
- **寮生活のサポート**：日程・予約、知恵袋、リンク、バッジ。
- **寮生・権限**：寮生情報、関係者が利用できる管理機能。
- **サイトの設定**：ホームの内容と順序、イベントの選択肢、機能の公開範囲、サイトの見た目。

### 関係者に協力を依頼する

RAが「関係者の権限」で必要な機能を許可し、保存します。関係者は許可されたメニューから作業します。初期状態では管理機能は未許可です。RA任命、関係者への権限付与、全寮生の一括退寮はRA専用です。

関係者用ログインは区分ごとの共有アカウントです。個人ごとの名前や作業履歴を区別する運用には対応していません。

### ホームと設定の使い分け

- **ホームの編集**：何を載せるか、どの順番で載せるかを変更。
- **機能の公開範囲**：寮生が使える機能を公開・試験公開・非公開に切り替え。
- **サイトの表示設定**：全員に共通する色・画像・表示・動きなどを調整。
- **自分の設定**：自分のブラウザーで使う言語・明るさ・「動きを控えめにする」を変更。動きの初期値は端末の設定に合わせ、変更はそのブラウザーに保存されます。

## 困ったとき

| 状況 | 確認すること |
| --- | --- |
| 関係者で管理できない | 選んだ区分と、RAが許可した機能を確認します。 |
| ツールや予約ページが出ない | その機能・日程が公開されているかRAに確認します。 |
| 投稿・保存が進まない | 処理中の表示を確認し、連打せず待ちます。通信が切れた場合は再読み込みして保存結果を確認します。 |
| 表示が古い | 画面を再読み込みします。 |
| 使い方を見直したい | 「自分の設定」から「使い方ガイド」を開きます。 |

運営に連絡するときは、開いていた画面、時刻、行った操作、表示された案内を伝えると確認がしやすくなります。
