# WISH Events 利用ガイド

WISH Eventsは、早稲田大学国際学生寮WISHのイベント参加、お知らせ、イベントごとのトーク、アンケート、集金確認をひとつにまとめたWebサイトです。スマートフォンとパソコンのどちらからでも利用できます。

## サイトを開く

### [WISH Eventsを開く](https://wish-events-info.vercel.app)

ブックマークまたはスマートフォンのホーム画面に追加しておくと、次回からすぐに開けます。

## はじめて使うとき

1. [WISH Events](https://wish-events-info.vercel.app)を開きます。
2. 「Googleでログイン」を押し、早稲田大学のGoogleアカウント（`@waseda.jp`）を選びます。
3. 初回プロフィールを登録します。
4. 必須項目を確認し、LINEのQRコード画像をアップロードして保存します。

プロフィールには氏名、学籍番号、部屋、学部・学年、話せる言語、国籍・居住経験のある国や地域、自己紹介、SNSなどを登録できます。公開したくない情報は「マイページの公開設定」で表示・非表示を選べます。

> LINE QRはイベント運営に必要な連絡先として登録します。

## スマートフォンの基本操作

画面下のタブから、よく使う3つの画面へ移動できます。

| タブ | できること |
| --- | --- |
| ホーム | 今週のイベント、重要なお知らせ、回答待ちのアンケートなどを確認 |
| イベント | 日付や条件でイベントを探し、詳細の確認や参加申込 |
| トーク | 参加したイベントの連絡、画像、投票、アンケートを確認 |

自分のプロフィール画像を押すと、マイページ、プロフィール編集、寮生一覧、言語切替、ログアウトなどのメニューが開きます。RAには管理ダッシュボードも表示されます。

## イベントを探して申し込む

1. 画面下の「イベント」を開きます。
2. キーワード、日付、会場、対象者などでイベントを探します。
3. 気になるイベントカードを押し、日時、場所、参加費、定員、説明を確認します。
4. 「申し込む」を押します。事前質問がある場合は回答してから申し込みます。
5. 申込後は、そのイベント専用のトーク画面へ移動します。

ホームのイベント欄は横にスクロールできます。イベントカードのハートを押すと「いいね」、詳細画面ではコメントや返信もできます。

申込を取り消せるイベントでは、イベント詳細からキャンセルできます。定員に達している場合や受付期間外の場合は、画面に表示される案内を確認してください。

## イベントのトークを使う

参加したイベントには専用のトークがあります。RAからの当日案内や変更連絡を確認し、必要に応じて返信できます。

- メッセージや写真を送る
- メッセージにリアクションする
- 投票に回答する
- サイト内アンケートや外部フォームを開く
- イベント詳細への案内カードを開く

新着があると「トーク」に赤いバッジが付きます。トークを開いて内容を確認すると既読になります。画像はタップすると大きく表示できます。

「友達」トークは試験機能です。RAの公開設定によって「BETA」として表示される場合や、表示されない場合があります。

## お知らせ・コメント・いいね

ホームのお知らせは新しいものから縦に並びます。タイトルを押すと、本文、作成者、作成日時、いいね、コメントを確認できます。

コメント数はタイトル付近の `(件数)` で確認できます。コメントには返信でき、RAの投稿はプロフィール画像まわりの専用リングで見分けられます。送信中は進捗表示が出るため、完了するまで同じボタンを繰り返し押さずにお待ちください。

## 参加費と支払い確認

集金が必要なイベントでは、イベント詳細に参加費、集金日、任意の支払い先が表示されます。

銀行振込などの支払いはRAが手動で確認します。支払い後すぐに「支払い済み」にならない場合があります。確認状況に疑問があるときは、そのイベントのトークでRAへ連絡してください。

## マイページとプロフィール

右上のプロフィール画像から「マイページ」を開くと、自己紹介、参加イベント、バッジ、登録したSNSなどを確認できます。公開されているInstagramやXのアイコンを押すと、その人のSNSへ移動できます。

「プロフィール編集」では、次の内容をいつでも変更できます。

- プロフィール画像と任意のカバー画像
- 話せる言語、国籍、居住経験のある国・地域
- 自己紹介、Instagram、LINE、X
- 参加したイベント、SNS、言語、国籍情報をマイページに表示するか
- プロフィールのアクセントカラー

国・地域と言語は検索して選べます。保存が終わると自分のマイページへ移動します。

## RA向け：管理ダッシュボード

RAは右上のプロフィール画像から「管理ダッシュボード」を開きます。スマートフォンでもすべての管理機能を利用できますが、参加者一覧やホーム画面の構成など広い画面が必要な作業はパソコンが便利です。

管理画面上部のアイコンメニューで機能を切り替えます。下の内容だけが切り替わるため、管理画面を開き直す必要はありません。スマートフォンではメニューを横にスクロールしてください。

| 管理メニュー | 主な用途 |
| --- | --- |
| 概要 | イベント状況の確認 |
| イベント作成 | イベント、定員、参加費、事前質問、企画メンバーの設定 |
| お知らせ作成 | 寮生向けのお知らせを投稿 |
| RA管理 | RAメンバーの管理 |
| 寮生管理 | 寮生と住居情報の管理 |
| バッジ管理 | マイページに表示するバッジの管理 |
| ホーム編集 | ホームに表示する内容と並び順の変更 |
| 会場・対象 | イベント作成時の選択肢を管理 |
| 公開設定 | 友達トークなどの試験機能を公開・BETA・非公開から選択 |

イベント詳細の参加者管理では、申込者、事前質問の回答、支払い状況を確認できます。必要に応じて参加者CSVを出力し、集金を確認した寮生にはRAが支払い済みのチェックを付けます。

## 画面が読み込み中のとき

ページ移動中は画面上部のプログレスバーと、移動先に似た薄い読み込み表示が出ます。保存、申込、コメント送信、画像アップロードにも処理中の表示があります。通信状況によって少し時間がかかる場合は、その表示が消えるまでお待ちください。

長時間変わらない場合は、次の順に試してください。

1. 通信環境を確認する
2. 画面を一度再読み込みする
3. ログアウトして、早稲田大学のGoogleアカウントでログインし直す
4. 解決しない場合は、画面名、発生時刻、表示されたメッセージ、スクリーンショットを添えてRAへ連絡する

## よくある質問

### ログインできません

個人のGmailではなく、早稲田大学のGoogleアカウント（`@waseda.jp`）を選んでください。複数のGoogleアカウントにログインしている場合は、アカウント選択画面で確認してください。

### プロフィールを保存できません

必須項目とLINE QRの登録を確認してください。「permission denied」などのメッセージが表示された場合は、メッセージのスクリーンショットを添えてRAへ連絡してください。

### 写真をアップロードできません

PNG、JPEG、WebP形式の画像を使用してください。プロフィール画像は5MB以下が目安です。ファイルを選ぶほか、対応している画面ではアップロード欄へのドラッグ＆ドロップも利用できます。

### 申込後にトークが見つかりません

画面下の「トーク」を開き、「イベント」タブを確認してください。それでも表示されない場合は、イベント詳細を開いて申込状態を確認してください。

### 表示言語を変えたいです

右上のプロフィール画像を押し、メニュー内の言語切替から日本語または英語を選んでください。ログイン前はログイン画面から切り替えられます。
