# 継続改善の実装・確認（2026-09-05）

## 追加した改善

- イベント一覧：開催状態と日付条件の競合を解消。日付・期間・月を選ぶと開催状態を解除し、開催状態を選ぶと日付条件を解除する。検索とカテゴリは維持する。逆転した期間を拒否する。
- スマホ：主な移動先をホーム・イベント・トーク・ツールに統一。ツールを目的別に整理。アカウントメニューを分類し、画面内でスクロールできるようにした。操作箇所の高さを44pxに揃えた。
- 遷移：読み込み表示が残る間は連続操作を防止。エラー表示とブラウザーの復帰時は操作ロックを解除する。読み込み失敗時の再試行・再読み込み・エラー番号を表示する。バックエンドのGET/HEAD応答待ちに12秒の上限を設けた。書き込みの自動再送はしない。
- チャット：無料のSWR 2.4.1で再接続・再表示時の補完と再試行を共通化。通常は20秒間隔、50件以上の不足がある場合は短い間隔で続きも取得する。非表示・オフライン時の定期取得を止める。接続状態と再試行を表示する。既存の本文・画像・リアクション・投票・履歴の仕組みは維持した。
- 未読：イベントの全メッセージをヘッダーへ取得せず、未読の有無だけをDBから返す。
- 権限：通常画面とServer Actionで退寮済みアカウントを拒否。DBポリシー・公開関数・Storageにも在寮確認を加える更新SQLを作成した。退寮後は本人の過去の参加イベント概要だけを取得できる。
- 関係者ログイン：個別・共通パスワードの併用時にAuth側パスワードが交互に変わる競合を防ぐ。管理キーがない既存アカウントのログイン方法は維持した。

## 無料運用の条件

追加ライブラリーSWRは無料のOSSで、メッセージ数に応じたライブラリー料金はない。既存のSupabaseを使い、新しい有料チャットサービスは契約していない。

ただし、Supabase FreeにはDB 500MB、ファイル1GB、通信量などの上限がある。「利用量・保存量が無限に増えても永久無料」は保証できない。履歴の自動削除や有料プランへの変更は行っていない。利用量が上限へ近づいた場合は、保存期間・アーカイブ先・自前サーバーなどの運用判断が必要。

参照： [Supabase公式料金](https://supabase.com/pricing)、[SWR](https://swr.vercel.app/)。
