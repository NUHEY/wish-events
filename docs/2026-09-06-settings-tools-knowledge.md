# 個人設定・ツール・質問機能の改善

## 実装内容
- `/settings` に言語・明るさ・プロフィールと公開範囲への入口・使い方を集約。ログイン前も言語と明るさを変更可能。
- お知らせの全件表示を見出し横の短いリンクへ変更。
- 管理ボードの「行いたいことを選ぶ」と重複するリンク一覧を削除。管理権限に応じたメニューは維持。
- カテゴリはフィルターボタンを押すと表示。選択中のカテゴリのみ通常表示し、選択時には閉じる。
- イベント募集をツール一覧の先頭に移動。
- 質問箱をWISH知恵袋へ統合。投稿時に閲覧範囲（全員／本人とRA）・回答者（全員／RA）を指定。非公開なら回答はRAのみ。旧URLは非公開相談フォームへ転送。
- 管理を委任された関係者は公開質問を管理可能。非公開相談の閲覧とRA限定回答は実際のRAのみ。
- 旧質問・回答は移行し、匿名・非公開を保持。既存の質問箱テーブルは閲覧用の履歴として保存。
- 古いRA一律制限を入口処理から除去し、ページ・操作・DBの機能別権限に統一。

## 表示基準
- 主要な操作領域は44px以上。
- カード画像は約1.618:1。文字部分の固定高を外し、余白は内容に追従。
- イベント一覧はスマホ2列、タブレット3列、広い画面4列。
- 見出し、日付、ボタンを同じ行に無理に収めず、読める単位で折り返す。
- 閲覧・回答の範囲は投稿前に文章で説明。操作中は連打を防ぎ、失敗を表示。

## ツールで直した不具合
- 日程の保存値の `+00:00` と `.000Z` を同じ日時として扱い、選択と人数集計が消える問題を修正。
- 通信中の二重操作を防止。存在しない日付、短すぎる時間帯、NaN設定を拒否。
- 1000枠を超える空き時間や不正な値を黙って切り捨てず、全体を拒否して保存済みの値を保護。
- 管理を委任された関係者を自動でRA参加者にしない。

## 検証
- Node回帰テスト73件成功。
- TypeScript型検証・本番ビルド成功。Lintは既存の画像最適化に関する警告のみ。
- PostgreSQLで旧質問・回答の移行、再実行、匿名ID保護、RA限定閲覧・回答、削除・解決権限、移行通知なしを検証済み。
- ローカル画面で320pxのカードに横はみ出しがないこと、フィルターの展開・選択・閉じるとURL反映を確認。
- 個人設定・知恵袋の追加画面検証と本番反映は、ブラウザー接続復旧後に実施する。
